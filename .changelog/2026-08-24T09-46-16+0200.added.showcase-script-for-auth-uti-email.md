# added showcase script for auth.uti.email

Added `scripts/showcase.mjs` — a single-session Playwright script that:
- Logs in to auth.uti.email with admin credentials
- Takes screenshots of the login page, filled form, post-login dashboard, home, certificates, and a domain detail view
- All actions run in one browser context so session cookies persist across page navigations
- Outputs PNG files to `./screenshots/`

Also added a `clickText` action type to `server.mjs` for clicking elements by visible text (uses Playwright's `getByText` locator).

Run with: `bun run showcase`
