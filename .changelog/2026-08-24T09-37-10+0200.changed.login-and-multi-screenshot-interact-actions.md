# added login and multi-screenshot interact actions

Extended `runInteractions` to support the login-and-screenshot workflow:

- Added `waitForSelector` and `waitForURL` actions to safely wait after navigation (e.g. post-login redirect)
- Added `select` action for dropdown fields
- Screenshots are now collected as an array `screenshots: [{label, data}]` — each step can carry a `label`
- `screenshot` (last captured) is still returned for backward compatibility
- Fixed viewport to 1280×900 for consistent screenshot dimensions
- Fixed `wait` action — `waitForTimeout` does not accept an options object in Playwright
